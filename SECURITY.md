# Security & data policy

## Public repo

Source is public for portfolio and collaboration on **code**. It must not contain real personal health data.

## Reporting

If you find a vulnerability or accidental personal data in this repository, contact: **christophe@vastpakt.be** (do not open a public issue with the sensitive content).

## Maintainer rules

- See `docs/ops/data-discipline.md`  
- Run `sh scripts/check-data-discipline.sh` before push  
- Production: `docs/ops/production-checklist.md`
