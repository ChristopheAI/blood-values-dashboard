# Agent Learnings

Shared, evidence-cited cross-agent working memory for this repository under the
docs control plane.

Rules:
- Keep entries short, imperative, and reusable.
- Cite concrete evidence by file/symbol plus date.
- Do not record secrets, private health data, one-off values, or transcript-only guesses.
- Update this file in place; do not fork per-session learning files.
- Treat root `AGENTS.md` as human-owned; do not use learnings as root guidance.
